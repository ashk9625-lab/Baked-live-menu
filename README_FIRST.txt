BAKED LIVE MENU - SEPARATE STOCK LISTS

This build keeps the existing Baked Live Menu and adds separate inventory management for:
- CUSTOMER STOCK
- NSFT STOCK

ADMIN:
Open Admin > Stock Lists.
Choose CUSTOMER STOCK or NSFT STOCK, enter quantities, then click SAVE SELECTED STOCK.
The two quantity lists are stored separately.

IMPORTANT:
This package is intended to replace the existing core website files in the same repository. Keep your existing image/icon/manifest assets already in the repository.
