# Baked Africa Live Menu

A mobile-friendly live product menu connected to Supabase and hosted on Vercel.

## Included

- Public live inventory catalogue
- Search and category filters
- Shopping cart and customer checkout
- Automatic order creation and stock deduction
- Admin login
- Product management
- Stock in / stock out controls
- Order status management
- Inventory movement history

## Local preview

Open `index.html` directly, or run:

```bash
npm run dev
```

## Deployment

The project is configured as a static Vercel site. Import the GitHub repository into Vercel or run a Vercel deployment from the project directory.

## Supabase

The frontend uses the project's public Supabase publishable key. Secure data changes remain protected by Row Level Security and authenticated database functions.
